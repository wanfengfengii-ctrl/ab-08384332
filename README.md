# 标记布局重建工作台（超声导轨校准）

超声导轨校准夹具上的反射标记标签脱落后，测量仪只保留**全部两两间距的无序多重集**。
本工作台在浏览器中纯前端重建标记布局：导入或编辑标记数与间距，启动完整搜索，
给出裁决（无解 / 唯一 / 多个非镜像布局）、规范最小布局与第二份歧义见证，
并以共用刻度尺对照候选位置、逐距离列出消耗记录。**全程不调用任何业务后端。**

## 问题模型

- 4–18 个**位置互异**的标记，恰有 `n(n−1)/2` 个间距；
- 间距**非负、最多三位小数**；计算前统一 **×1000 缩放为整数**（字符串级精确缩放，
  无浮点误差），重复间距的次数在多重集中原样保留；
- 求解器对缩放后的整数多重集做**完整回溯搜索**（Skiena 最大间距剪枝 +
  节点/解数安全预算），保证与多重集**精确一致**；
- 输出布局一律将**最左点平移至零**；**镜像视为同一布局**，以字典序较小者为规范形式；
- 裁决语义：
  - `无解`：完整搜索后无任何布局；
  - `唯一布局`：恰一个非镜像布局，给出规范布局；
  - `多个非镜像布局`：给出规范最小布局与第二份歧义见证（界面展示前两个，统计中给出总数）；
  - `无法判定`：仅当安全预算耗尽（正常输入不会触发）。
- 修改任何输入（标记数 / 间距 / 导入 / 示例）都会**清除旧裁决**并终止进行中的搜索。

## 本地开发

```bash
npm install
npm run dev        # 开发服务器
npm run typecheck  # 类型检查
npm run build      # 产物到 dist/
npm run verify     # 本地验收：打包求解器并运行 verify/run.mjs
```

求解在 Web Worker 中执行，界面不冻结；Worker 不可用时自动回退主线程。

## 输入与导入

- 间距文本：空格 / 换行 / 中英文逗号 / 分号 / 顿号 / 竖线分隔；
- 导入文件（`.json` / `.txt` / `.csv`）：
  - JSON 对象：`{"n": 6, "distances": [1, 2, 3, 4, 5, 6]}`
  - JSON 数组：`[1, 2, 3, 4, 5, 6]`
  - 纯文本数字列表；
- 内置示例：唯一解、经典同距歧义对（`{0,1,4,10,12,17}` 与 `{0,1,8,11,13,17}`）、
  三位小数、重复间距、无解；亦可按当前 n 随机生成可解实例。

## Docker 交付

```bash
# 启动静态 Web（默认宿主机端口 8080，可用 WEB_PORT 覆盖）
WEB_PORT=9000 docker compose up --build web

# 运行可执行验收服务（先等 web 健康，再跑验收套件 + Web 冒烟，退出码即结论）
docker compose up --build verify
```

- `Dockerfile` 多阶段：`builder`（类型检查 + 构建 + 求解器打包）→
  `web`（nginx 静态站点，含 `HEALTHCHECK`，健康端点 `/healthz`）→
  `verify`（Node 验收服务镜像）；
- `docker-compose.yml`：
  - `web`：静态 Web，`ports: "${WEB_PORT:-8080}:80"` 可配置宿主机端口，带健康检查；
  - `verify`：**可执行验收服务**，`depends_on: web (service_healthy)`，
    运行 `verify/run.mjs`：47 项验收（解析缩放、三类裁决、镜像归并、平移归零、
    重复多重性、零间距拒绝、消耗记录自洽、随机模糊 + 独立暴力枚举交叉验证、
    n=18 上限规模），并对 `WEB_URL`（默认 `http://web`）做 `/healthz` 与首页冒烟；
    全部通过退出码 0，任一失败退出码 1。

## 目录结构

```
src/
  solver/
    parse.ts      # 文本解析、×1000 精确整数缩放、格式化
    layout.ts     # 间距多重集、逐距离消耗记录、多重集比较
    turnpike.ts   # 完整回溯求解器（镜像归并、平移归零、安全预算）
    index.ts      # 验收包入口
  solverWorker.ts # Web Worker 包装
  components/     # 输入面板 / 裁决横幅 / 共用刻度尺 / 解卡片
  App.tsx         # 工作台装配（修改输入即清除旧裁决）
verify/run.mjs    # 可执行验收服务入口
Dockerfile / docker-compose.yml / nginx.conf
```
